# TriLingo 三語道場

英文、日文、韓文的遊戲化自學網頁。三種語言各自累積 XP、各自升段，用連勝、每日任務、寶箱和小遊戲讓「每天學一點」變成習慣。

**線上版：<https://threshadow98171314.github.io/TriLingo/>**（手機開啟後可用瀏覽器的「加到主畫面」當成 App 使用）

| 語言 | 目標 | 路線 |
| --- | --- | --- |
| 英文 | 多益 TOEIC 990 分滿分 | 橘色 → 棕色 → 綠色 → 藍色 → **金色**證書 |
| 日文 | 通過 JLPT N1、旅遊溝通、看動漫不用字幕 | 五十音 → N5 → N4 → N3 → N2 → N1，另有「旅遊會話」「動漫・日劇」主題路線 |
| 韓文 | 旅遊溝通、看韓劇不用字幕 | 韓文字母 → 初級 1–2 → 中級 1–2 → 高級 1–2（對照 TOPIK 1–6 級），另有「旅遊會話」「韓劇・綜藝」主題路線 |

目前有內容的關卡（共約 1,630 個單字、短句與題目）：

- 英文：**橘色**、**棕色**證書（會議、電話、電子郵件、Part 5 詞性題、進行式與完成式、Part 2 進階聽力）
- 日文：**五十音**（平假名、片假名交錯學）、**N5**、**N4**（て形、ない形、た形、可能形、意向形、授受表現、條件形）、**N3**（被動、使役與使役被動、敬語入門、ように・ことに、推測與傳聞、はず・わけ・ところ・ばかり、擬聲擬態語）、**N2**（機能語、わけ與推斷、逆接、變化與時間、〜ざるを得ない・〜かねない、商務日語、複合動詞、慣用句）；旅遊會話 7 個單元（點餐、交通、購物免稅、住宿、問路、緊急就醫）、動漫 3 個單元（高頻詞、人稱、口語縮約形）
- 韓文：**字母**、**初級 1**、**初級 2**（-고・-지만・-아서／어서、-(으)ㄹ 거예요、-(으)ㄹ까요、-아／어야 돼요）；旅遊會話 7 個單元、韓劇 3 個單元（高頻詞、稱呼、半語與語尾）

其餘關卡的頁面已經建好，會顯示預定的單元大綱，補上資料就能直接開放。

## 開始使用

需要 Node.js 20 以上。

```bash
npm install
npm run dev      # 開發模式，預設 http://localhost:5173
npm run build    # 型別檢查＋打包到 dist/（純靜態檔，可放到任何靜態主機）
npm run preview  # 預覽打包結果
npm test         # 單元測試
```

打包結果使用相對路徑與 hash 路由，放在子目錄（例如 GitHub Pages）也能直接運作。

## 段位

依序為 **鐵 → 銅 → 銀 → 金 → 白金 → 鑽石 → 大師 → 宗師 → 菁英 → 聖哲**。聖哲以外的每個段位再分 III → II → I 三階，總共 28 階，讓升段的回饋更頻繁。

| 段位 | 累積 XP | 段位 | 累積 XP |
| --- | ---: | --- | ---: |
| 鐵 | 0 | 鑽石 | 10,000 |
| 銅 | 300 | 大師 | 20,000 |
| 銀 | 1,000 | 宗師 | 35,000 |
| 金 | 2,500 | 菁英 | 60,000 |
| 白金 | 5,000 | 聖哲 | 100,000 |

門檻定義在 `src/core/ranks.ts` 的 `TIERS`，要調整節奏改這裡就好。

## 讓人想一直學下去的機制

- **連勝**：每天有學習就延續；連勝保護可以救回缺席的一天；3、7、14、30…天有里程碑獎勵。
- **每日目標**：三種語言合計的 XP 目標（20／50／100／200 可選），達成有獎勵。
- **每日任務**：每天由日期決定 3 個任務，全部領完可以開每日寶箱。
- **三語全修**：同一天三種語言都練習有額外獎勵，避免偏廢。
- **連擊**：連續答對會累積連擊，音效越來越高，結算時有加成。
- **星等**：每堂課依答對率拿 1–3 顆星，可以重練補滿。
- **不定時寶箱**：過關後有 25% 機率掉落金幣，3% 機率開出**黃金寶箱**（60–120 金幣）。
- **幸運星**：過關時有 5% 機率降臨，這堂課的 XP 直接加倍。
- **段位與升段動畫**、**成就**（54 個，其中 7 個是只顯示提示的**隱藏成就**）、**圖鑑**（收集學過的字，顯示熟練度）、**學習熱力圖**。
- **間隔複習（SRS）**：學過的字依 1 → 3 → 7 → 14 → 30 → 60 → 120 天排程；答錯會提早回到複習。
- **商店**：金幣可換連勝保護、雙倍 XP 藥水、頭像。
- **喵師父**：首頁的吉祥物，會依時段、連勝、複習進度跟你說話，也會分享三種語言的冷知識。
- **知識補充站**：首頁每次打開都隨機一則小知識（語言小知識、易混淆、文化、考試攻略、學習方法，共 50 則），會盡量避開最近看過的；課程結算畫面也會附一則「你知道嗎？」。
- **一句話學三語**：英、日、韓諺語各一句，附讀音與朗讀，每次打開都隨機換一組。
- **接續學習**：首頁最上方直接顯示「▶ 繼續上次在學的語言」與待複習數；語言卡片的按鈕也直接進入下一課，想看整條路線再點「學習路線」。
- **現在不方便聽**：聽力題旁邊按一下，接下來一小時的聽力題改成看文字作答（設定頁可以提早恢復）。

### 實戰模擬考

每種語言的「模擬考」分頁都有仿照正式考試題型的計時測驗，題目全部是原創，每次從題庫重新抽題：

| 模擬考 | 題型 | 時間 |
| --- | --- | --- |
| 多益模擬考：橘色・棕色 | Part 2 應答、Part 3 對話（聽力）、Part 5 句子填空、Part 6 段落填空、Part 7 閱讀 | 20 分鐘・約 28 題 |
| 日檢 N5／N4 模擬試験 | 漢字讀音（從課程單字自動出題）、漢字寫法、填空、意思相近、文法、★ 句子重組、讀解、即時應答、對話理解 | 30 分鐘・約 30 題 |
| 日檢 N3／N2 模擬試験 | 同上，再加上「用法」（選出用法正確的句子）、N2 的「語形成」、商務信件與資訊檢索的讀解 | 40–45 分鐘・約 35 題 |
| TOPIK I 모의고사 | 聽問題選回答、接下去的話、地點、話題、對話內容（聽力）；主題、填空、公告、短文（閱讀） | 30 分鐘・約 27 題 |

- 可以跳題、🚩 標記待確認的題目，時間到自動交卷；聽力第一次看到題目時自動播放，男女聲用不同語音或音高區分。
- 交卷後顯示答對率、各大題成績與程度判斷（TOPIK 依正式門檻換算 1 級、2 級），並可以逐題檢討：正解、你的答案、翻譯、解析、聽力稿。
- 記錄每份模擬考的最佳與上次成績，會跟著雲端同步；另有三個模擬考成就。

### 新手引導與說明

- 第一次打開會跳出五頁的導覽，最後一頁選要從哪個語言開始。
- 首頁、學習路線、遊樂場、模擬考、圖鑑、五十音表第一次打開時，上方會有一張說明卡，按「知道了」就不再出現。
- 上課時每種題型（教學卡、拼字、句子重組、打字、聽力、漢字讀音…）第一次出現，會在題目上方顯示一行操作提示。
- 右上角 ❓ 是「使用說明」頁，用問答整理所有功能；設定頁可以重看導覽與所有提示。看過的說明會跟著雲端同步。

### 特效與彩蛋

- **特效**：答對時的星光與「+1 XP」、5／10／15／20／30／50 連擊的大字橫幅、答錯時畫面輕震、全對的 PERFECT 印章與煙火、升段煙火、金幣飛進錢包。
- **季節特效**：首頁背景會依季節飄落櫻花（3/15–4/15）、螢火蟲（7–8 月）、落葉（10–11 月）或雪花（12–2 月）；萬聖節前一週還會混進南瓜和蝙蝠。
- 兩種特效都可以在「設定 → 顯示」關閉；系統開啟「減少動態效果」時會自動停用。
- **彩蛋**：網站裡藏了 20 個彩蛋，有鍵盤秘技、可以對喵師父說的悄悄話、要連點的地方、特定日期或時間才會出現的驚喜。第一次發現會拿到金幣，並收進「成就 → 彩蛋收藏冊」；收藏冊裡看得到每個彩蛋的提示。

### 題型

選擇（看字選義、看義選字、聽音選義）、日文漢字讀音題（干擾選項是促音／長音／清濁音的近似讀音，同日檢題型）、字卡拼字、句子重組、羅馬拼音輸入、配對、克漏字、聽問題選回應（多益 Part 2 形式）。

**日文打字題**：看中文或聽發音，用日文輸入法打出單字、短句。每一段漢字都可以打漢字或假名（「ちょっと待って」「ちょっとまって」都算對），只差平假名／片假名時算對但會提醒標準寫法。輸入法選字時按的 Enter 不會被當成送出；答錯時如果其實是打了另一種正確寫法，可以按「我的答案也對」改判。不方便打字時按「現在不方便打字」，這一場改出選擇題；設定頁也可以整個關掉。遊樂場另有「打字特訓」（看中文打＋聽打）。手寫題沒有做：自動批改需要辨識模型，而且「シ／ツ」「ソ／ン」這類只差筆順方向的字，用圖形比對分不出來。

日文單字題只顯示假名：漢字會把意思直接洩漏給中文母語者，真正要練的是「聲音 ↔ 意思」。

每個單元最後有**單元測驗**（答對率 80% 通過）。測驗永遠開放，已經會的內容可以直接考過跳級。

## 新增內容

所有內容都是資料，不需要改任何畫面程式。以新增日文 N1 的一個單字單元為例：

```ts
// src/content/ja-n1.ts
import { ja, vocabUnit } from './dsl';

export const N1_UNITS = [
  vocabUnit('ja.n1.society', '🏙️', '社會', 'しゃかい', [
    // 原文用「漢字[よみ]」標註讀音；例句寫成「日文|中文」
    ja('経済[けいざい]', '經濟', '経済[けいざい]のニュースを読[よ]みます。|看經濟新聞。'),
    ja('環境[かんきょう]', '環境', '環境[かんきょう]を守[まも]りましょう。|一起保護環境吧。'),
    // …
  ]),
];
```

再到 `src/content/ja.ts` 的 `UNITS` 加上 `'ja.n1': N1_UNITS`，並到 `src/content/meta.ts` 把做好的單元從 N1 的 `planned: [...]` 移除（還沒做的可以繼續留著，測試會檢查已上線的單元沒有還掛在清單裡）。課程切分、單元測驗、填字遊戲、圖鑑都會自動接上。

各語言的題目會打包成獨立的檔案（`en-*.js`、`ja-*.js`、`ko-*.js`），只有用到時才下載，所以內容越加越多也不會拖慢首頁。

- 英文用 `en()`、韓文用 `ko()`、字母用 `ch()`、句子用 `sj()`／`ss()`、克漏字用 `cz()`、聽力應答用 `qa()`，文法單元用 `grammarUnit()`。各函式的用法寫在 `dsl.ts` 的註解裡。
- 克漏字與應答題的**第一個選項是正確答案**，出題時會自動洗牌。
- 學習進度以項目 id（單元 id＋原文）儲存，**已經上線的單字不要改寫原文**，否則該字的進度會歸零。
- 寫完跑 `npm test`：內容測試會檢查 id 重複、振假名漏標、選項重複、分詞對不上原句等常見筆誤。

## 部署

推送到 `main` 分支時，GitHub Actions（`.github/workflows/deploy.yml`）會自動跑測試、打包並部署到 GitHub Pages，約一兩分鐘後線上版就會更新。

## 存檔與雲端同步

進度預設存在瀏覽器的 localStorage（鍵名 `trilingo.save.v1`），沒有後端。

**雲端同步**：到「設定 → 雲端同步」貼上一個只有 `gist` 權限的 GitHub 權杖，進度就會存到你 GitHub 帳號裡的一個私人 Gist（檔名 `trilingo-save.json`）。筆電、手機各連結一次之後，開啟 App、切回分頁、學習告一段落時都會自動同步。

- 合併規則是「進度只增不減」：段位 XP、星等、成就取較大值；單字熟練度取最後作答的那一份；設定與金幣取最後修改的那一份（`src/core/merge.ts`）。
- 限制：兩台裝置都在離線狀態下各自學習時，XP 取較大值而不是相加，其中一台離線期間多拿的 XP 會少算。
- 權杖只存在該裝置的瀏覽器（鍵名 `trilingo.cloud.v1`），不會包含在匯出的存檔裡。不用了可以到 GitHub 的 Settings → Developer settings → Personal access tokens 撤銷。

也可以到「設定 → 存檔」手動匯出／匯入 JSON。

## 語音

朗讀使用瀏覽器內建的 Web Speech API，有哪些語言的語音取決於瀏覽器與作業系統。Chrome 與 Edge 內建線上的英、日、韓語音；其他環境若缺少某個語言的語音，該語言的聽力題會自動改成其他題型，並在設定頁提示。
