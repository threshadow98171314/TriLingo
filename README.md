# TriLingo 三語道場

英文、日文、韓文的遊戲化自學網頁。三種語言各自累積 XP、各自升段，用連勝、每日任務、寶箱和小遊戲讓「每天學一點」變成習慣。

**線上版：<https://threshadow98171314.github.io/TriLingo/>**（手機開啟後可用瀏覽器的「加到主畫面」當成 App 使用）

| 語言 | 目標 | 路線 |
| --- | --- | --- |
| 英文 | 多益 TOEIC 990 分滿分 | 橘色 → 棕色 → 綠色 → 藍色 → **金色**證書，另有「多益題庫」「職場與生活情境」主題路線 |
| 日文 | 通過 JLPT N1、旅遊溝通、看動漫不用字幕 | 五十音 → N5 → N4 → N3 → N2 → N1，另有「情境小鎮」「旅遊會話」「動漫・日劇」主題路線 |
| 韓文 | 旅遊溝通、看韓劇不用字幕 | 韓文字母 → 初級 1–2 → 中級 1–2 → 高級 1–2（對照 TOPIK 1–6 級），另有「情境小鎮」「旅遊會話」「韓劇・綜藝」主題路線 |

## 開始使用

需要 Node.js 20 以上。

```bash
npm install
npm run dev      # 開發模式，預設 http://localhost:5173
npm run build    # 型別檢查＋打包到 dist/（純靜態檔，可放到任何靜態主機）
npm run preview  # 預覽打包結果
npm test         # 單元測試
```

打包結果使用相對路徑與 hash 路由，放在子目錄（例如 GitHub Pages）也能直接運作。

## 段位

依序為 **鐵 → 銅 → 銀 → 金 → 白金 → 鑽石 → 大師 → 宗師 → 菁英 → 聖哲**。聖哲以外的每個段位再分 III → II → I 三階，總共 28 階，讓升段的回饋更頻繁。

| 段位 | 累積 XP | 段位 | 累積 XP |
| --- | ---: | --- | ---: |
| 鐵 | 0 | 鑽石 | 10,000 |
| 銅 | 300 | 大師 | 20,000 |
| 銀 | 1,000 | 宗師 | 35,000 |
| 金 | 2,500 | 菁英 | 60,000 |
| 白金 | 5,000 | 聖哲 | 100,000 |

門檻定義在 `src/core/ranks.ts` 的 `TIERS`，要調整節奏改這裡就好。

## 讓人想一直學下去的機制

- **連勝**：每天有學習就延續；連勝保護可以救回缺席的一天；3、7、14、30…天有里程碑獎勵。
- **每日目標**：三種語言合計的 XP 目標（20／50／100／200 可選），達成有獎勵。
- **每日任務**：每天由日期決定 3 個任務，全部領完可以開每日寶箱。
- **三語全修**：同一天三種語言都練習有額外獎勵，避免偏廢。
- **連擊**：連續答對會累積連擊，音效越來越高，結算時有加成。
- **星等**：每堂課依答對率拿 1–3 顆星，可以重練補滿。
- **不定時寶箱**：過關後有 25% 機率掉落金幣，3% 機率開出**黃金寶箱**（60–120 金幣）。
- **幸運星**：過關時有 5% 機率降臨，這堂課的 XP 直接加倍。
- **段位與升段動畫**、**成就**（67 個，其中 7 個是只顯示提示的**隱藏成就**）、**圖鑑**（收集學過的字，顯示熟練度）、**學習熱力圖**。
- **間隔複習（SRS）**：學過的字依 1 → 3 → 7 → 14 → 30 → 60 → 120 天排程；答錯會提早回到複習。
- **商店**：道具（連勝保護、雙倍 XP 藥水、連擊護符、幸運草、時光沙漏）；外觀十一大類：33 種插畫頭像（高級頭像會動）、27 款頭像框（其中 14 款**會動**：星軌、極光、火焰、櫻吹雪、霓虹、錦鯉、金龍、鳳凰…）、**學習夥伴**（上課時陪在進度條旁，答對會跳、答錯會難過）、**名牌特效**（金色流光、彩虹、霓虹、烈焰）、**名片背景**（9 幅插畫：晚霞海面、竹林、東京鐵塔與南山塔的城市夜景、星空流星、櫻花樹、極光雪山、海浪帆船、旋轉銀河、煙火大會）、**答對音效**（22 種：風鈴、木琴、8-bit、太鼓、喵喵、拇指琴、鋼琴、正解叮咚、RPG 升級、拍手、日本箏、伽倻琴、音樂盒、勝利號角…可試聽）、**飄落特效**（17 種：楓葉、櫻花、雪花、銀杏、螢火蟲、星空、愛心、泡泡、音符、三語字母、梅雨、平溪天燈、流星雨…，裝備後一年四季都飄，可試看）、**回頂特效**（12 種：火箭、氣球、紙飛機、喵師父跳跳、筋斗雲、新幹線、幽浮、金龍升天…）、整站主題色、答對特效、**稱號**（五個等級：銅、銀用金幣買；金、白金、傳說要達成條件才拿得到，例如連勝 100 天、三語都到聖哲、收集全部貼紙；等級越高特效越華麗，傳說稱號有皇冠與專屬特效）、喵師父裝扮；外觀用分類選擇器一次看一類；**三台扭蛋機**（並排的機台，點一台就能轉）：貼紙扭蛋（80 張日本、韓國、英語圈、台灣、季節、學習主題貼紙，四種稀有度，傳說貼紙會發光）、**動態貼紙扭蛋**（20 張會動的貼紙：揮手、眨眼、冒煙、心跳、搗麻糬…）、**外觀扭蛋**（抽一件還沒有的外觀，小機率是限定外觀）；**每日神秘商品三格**：限定（只在這裡賣的外觀）、特價（七折外觀、外觀福袋）、補給（十連抽特價、道具福袋、保底貼紙、金幣福袋）。所有圖示都是自己畫的可愛 SVG 插畫。
- **個人頁**（導覽列「個人」）：名片（頭像、暱稱、稱號、夥伴、背景）；**外觀切換**把買過的東西依種類排好，點一下換上、再點一次取下；**貼紙板**可以把收集到的貼紙拖上去布置（放大縮小、旋轉、調整前後，8 種板子背景，跟著雲端同步）；**學習紀錄**有三語段位、統計、熱力圖與段位階梯。「🏆 成就」頁只放成就與彩蛋收藏冊。
- **回到頂端**：每個頁面往下捲之後右下角會出現按鈕，按下去播放「回頂特效」並回到最上面。
- **喵師父**：首頁的吉祥物，會依時段、連勝、複習進度跟你說話，也會分享三種語言的冷知識。
- **知識補充站**：首頁每次打開都隨機一則小知識（語言小知識、易混淆、文化、考試攻略、學習方法，共 50 則），會盡量避開最近看過的；課程結算畫面也會附一則「你知道嗎？」。
- **一句話學三語**：英、日、韓諺語各一句，附讀音與朗讀（🐢 慢速版），每次打開都隨機換一組。
- **最近 7 天 XP**：每天三種語言分色堆疊，滑鼠移上去（手機點一下）顯示各語言拿了多少 XP。
- **接續學習**：首頁最上方直接顯示「▶ 繼續上次在學的語言」與待複習數；語言卡片的按鈕也直接進入下一課，想看整條路線再點「學習路線」。
- **現在不方便聽**：聽力題旁邊按一下，接下來一小時的聽力題改成看文字作答（設定頁可以提早恢復）。

### 情境小鎮

一張可愛的小鎮地圖（三種語言各 16 個地點）：點便利商店、郵局、車站、銀行、醫院、飯店、公司…就能看到那裡會用到的單字、對話（附說話的人）和當地的文化小知識與使用時機。每個地點三課：單字、對話、蓋章挑戰，通過會在地圖上蓋印章。日文有神社、韓文有汗蒸幕、英文有機場（英文版對準多益常考的職場與生活情境）。

### 聽日文歌學日語

日文頁的「🎵 日文歌」分頁：

- **排行榜**：Billboard Japan Hot 100 榜上的歌（2026 年 10 月 14 日公布），嵌入官方頻道的 MV，每首都附 **Uta-Net（JASRAC 授權）的官方歌詞頁連結**。流行歌的歌詞有版權，網站和這個 repo 都是公開的，所以不放歌詞本身：使用者從官方歌詞頁複製貼上，歌詞只存在自己的瀏覽器與自己的私人 Gist。可以打開影片本身提供的日文字幕。
- **一鍵自動翻譯**：Chrome 用內建的翻譯（在裝置上翻譯，不上傳）；其他瀏覽器或不支援時，改用免費的 MyMemory 翻譯服務一句一句翻；也可以用 Google 翻譯開啟再貼回來。
- **經典童謠・唱歌** 12 首（ふるさと、紅葉、朧月夜、春が来た、荒城の月、赤とんぼ、七つの子、しゃぼん玉、花、浜辺の歌、さくらさくら、雪）：作詞者過世已久（或作者不詳），歌詞是公有領域，網站直接附日文歌詞、讀音、自己寫的中文翻譯與文言文法說明，影片是 YouTube 上可嵌入的演唱版本。
- 按「對時」跟著歌一句一句按，就能點任一句歌詞從那一句開始唱、播放時自動標出正在唱的那一句。也可以貼任何 YouTube 網址加入自己喜歡的歌。

### 觀念講堂

語言頁的「💡 觀念」分頁，共 46 篇短文，每篇附例句與語音、文末有小測驗：

- 英文 18 篇：多益總覽與時間分配、Part 1～7 各大題的解題技巧，以及詞性、時態、被動、分詞、關係詞、連接詞與介系詞、主動一致、假設語氣、不定詞與動名詞、比較級、介系詞搭配等常考文法。
- 日文 16 篇：は與が、地點助詞、動詞分類、て形、四種條件、授受、可能被動使役、推測與傳聞、はず・わけ・べき，以及敬語、打招呼的時機、委婉拒絕、口語縮約、自他動詞、和製英語、助數詞等「什麼時候這樣說」。
- 韓文 12 篇：收尾音、連音／鼻音化／硬音化、은/는 與 이/가、常用助詞、語體、敬語、-아요/어요、不規則變化、時態、連接語尾、想要能力與規定、稱呼。

### 實戰模擬考

每種語言的「模擬考」分頁都有仿照正式考試題型的計時測驗，題目全部是原創，每次從題庫重新抽題：

| 模擬考 | 題型 | 時間 |
| --- | --- | --- |
| 多益模擬考：橘色・棕色 | Part 2 應答、Part 3 對話（聽力）、Part 5 句子填空、Part 6 段落填空、Part 7 閱讀 | 20 分鐘・約 28 題 |
| 多益模擬考：綠色・藍色 | Part 1 照片描述（文字版）、Part 2 應答、Part 3 對話、Part 4 獨白（聽力）、Part 5、Part 6（含句子插入題）、Part 7（含雙篇閱讀） | 30 分鐘・約 37 題 |
| 日檢 N5／N4 模擬試験 | 漢字讀音（從課程單字自動出題）、漢字寫法、填空、意思相近、文法、★ 句子重組、讀解、即時應答、對話理解 | 30 分鐘・約 30 題 |
| 日檢 N3／N2 模擬試験 | 同上，再加上「用法」（選出用法正確的句子）、N2 的「語形成」、商務信件與資訊檢索的讀解 | 40–45 分鐘・約 35 題 |
| TOPIK I 모의고사 | 聽問題選回答、接下去的話、地點、話題、對話內容（聽力）；主題、填空、公告、短文（閱讀） | 30 分鐘・約 27 題 |
| TOPIK II 모의고사（3 級） | 接下去的話、接下來要做什麼、內容相符（聽力）；文法填空、意思相近、主題、短文（閱讀） | 30 分鐘・約 25 題 |

- 可以跳題、🚩 標記待確認的題目，時間到自動交卷；聽力第一次看到題目時自動播放，男女聲用不同語音或音高區分。
- 交卷後顯示答對率、各大題成績與程度判斷（TOPIK 依正式門檻換算 1 級、2 級），並可以逐題檢討：正解、你的答案、翻譯、解析、聽力稿。
- 記錄每份模擬考的最佳與上次成績，會跟著雲端同步；另有三個模擬考成就。

### 新手引導與說明

- 第一次打開會跳出五頁的導覽，最後一頁選要從哪個語言開始。
- 首頁、學習路線、遊樂場、模擬考、圖鑑、五十音表第一次打開時，上方會有一張說明卡，按「知道了」就不再出現。
- 上課時每種題型（教學卡、拼字、句子重組、打字、聽力、漢字讀音…）第一次出現，會在題目上方顯示一行操作提示。

### 題型

選擇（看字選義、看義選字、聽音選義）、日文漢字讀音題（干擾選項是促音／長音／清濁音的近似讀音，同日檢題型）、字卡拼字、句子重組、羅馬拼音輸入、配對、克漏字、聽問題選回應（多益 Part 2 形式）、聽對話或獨白回答問題（多益 Part 3／4，男女用不同的聲音唸，不方便聽時改成印出對話稿）、閱讀短文回答問題（多益 Part 7，含多篇閱讀）。多益 Part 1 沒辦法放照片，改成看（照片：…）的文字描述選出正確的句子。

**圖片題**：意思對得上插圖（動物、食物、地點、交通工具、日用品…共 105 張）的單字，教學卡會附圖，練習時會出「看字選圖」「看圖選字」。

**答對時的例句**：答對單字時顯示一句例句，從單字自己的例句和課程裡其他用到這個字的句子（最多三句）隨機挑一句，可以按「換一句」。三種語言學習路線上的單字都有三句例句（不夠的由 `ja-more.ts`／`en-more.ts`／`ko-more.ts` 的補充例句表補上）。

**日文、韓文打字題**：看中文或聽發音，用日文輸入法打出單字、短句（韓文用韓文鍵盤）。第一次打錯會指出差在哪裡（促音、長音、ん、濁音、拗音；韓文是子音、母音、收尾音），給第一個字的提示再試一次；答錯或看了提示的題目，回饋裡會教「這樣打」：每個字要按哪些鍵。每一段漢字都可以打漢字或假名（「ちょっと待って」「ちょっとまって」都算對），只差平假名／片假名時算對但會提醒標準寫法。輸入法選字時按的 Enter 不會被當成送出；答錯時如果其實是打了另一種正確寫法，可以按「我的答案也對」改判。不方便打字時按「現在不方便打字」，這一場改出選擇題；設定頁也可以整個關掉。遊樂場另有「打字特訓」（看中文打＋聽打）。手寫題沒有做：自動批改需要辨識模型，而且「シ／ツ」「ソ／ン」這類只差筆順方向的字，用圖形比對分不出來。

日文單字題只顯示假名：漢字會把意思直接洩漏給中文母語者，真正要練的是「聲音 ↔ 意思」。

每個單元最後有**單元測驗**（答對率 80% 通過）。測驗永遠開放，已經會的內容可以直接考過跳級。

## 新增內容

所有內容都是資料，不需要改任何畫面程式。以新增日文 N1 的一個單字單元為例：

```ts
// src/content/ja-n1.ts
import { ja, vocabUnit } from './dsl';

export const N1_UNITS = [
  vocabUnit('ja.n1.society', '🏙️', '社會', 'しゃかい', [
    // 原文用「漢字[よみ]」標註讀音；例句寫成「日文|中文」
    ja('経済[けいざい]', '經濟', '経済[けいざい]のニュースを読[よ]みます。|看經濟新聞。'),
    ja('環境[かんきょう]', '環境', '環境[かんきょう]を守[まも]りましょう。|一起保護環境吧。'),
    // …
  ]),
];
```

再到 `src/content/ja.ts` 的 `UNITS` 加上 `'ja.n1': N1_UNITS`，並到 `src/content/meta.ts` 把做好的單元從 N1 的 `planned: [...]` 移除（還沒做的可以繼續留著，測試會檢查已上線的單元沒有還掛在清單裡）。課程切分、單元測驗、填字遊戲、圖鑑都會自動接上。

各語言的題目會打包成獨立的檔案（`en-*.js`、`ja-*.js`、`ko-*.js`），只有用到時才下載，所以內容越加越多也不會拖慢首頁。

- 英文用 `en()`、韓文用 `ko()`、字母用 `ch()`、句子用 `sj()`／`ss()`、克漏字用 `cz()`、聽力應答用 `qa()`，文法單元用 `grammarUnit()`。各函式的用法寫在 `dsl.ts` 的註解裡。
- 克漏字與應答題的**第一個選項是正確答案**，出題時會自動洗牌。
- 學習進度以項目 id（單元 id＋原文）儲存，**已經上線的單字不要改寫原文**，否則該字的進度會歸零。
- 寫完跑 `npm test`：內容測試會檢查 id 重複、振假名漏標、選項重複、分詞對不上原句等常見筆誤。

### 單字庫

大量單字放在各關卡的「📚 單字庫」：照主題分組、不排在學習路線上、不會上鎖，每組約 25 個字（5 課＋小測驗）。用 `deck()` 加一組，字用一行一個的 `jaList()`／`enList()`／`koList()` 寫：

```ts
deck('ja.n3.bank.home1', '🏠', '家事與日用品', '生活與家庭', jaList(`
  家事[かじ]|家事|夫[おっと]と家事[かじ]を分[わ]けている。|和老公分攤家事。
  洗剤[せんざい]|清潔劑|洗剤[せんざい]がもうすぐなくなる。|清潔劑快用完了。
`)),
```

- 各關卡的單字庫分成好幾個檔案（例如 `ja-n3-bank1.ts`…），由 `ja-n3-bank.ts` 彙整。
- 測試會檢查單字庫的字沒有和同一個語言的其他單元重複。
- 已上線的組只能在後面加字，不要把字搬到別組（id 是「組的 id＋原文」，搬了進度會歸零）。

### 補充例句

單字答對時會從最多三句例句裡隨機挑一句。學習路線上的字如果例句不到三句，就在 `ja-more.ts`／`en-more.ts`／`ko-more.ts` 補上，一行一個「原文|例句|翻譯|例句2|翻譯2」，原文要和單字的寫法一模一樣（日文含讀音標註）：

```ts
冷[ひ]やす|スイカを冷[ひ]やして食[た]べましょう。|把西瓜冰過再吃吧。|熱[ねつ]があるので、頭[あたま]を冷[ひ]やしました。|因為發燒，冰敷了頭。
```

只加例句、不改單字，所以不影響學習進度。測試會檢查原文對得到單字、學習路線上的單字都有三句例句，英文例句裡一定要出現該單字。

## 部署

推送到 `main` 分支時，GitHub Actions（`.github/workflows/deploy.yml`）會自動跑測試、打包並部署到 GitHub Pages，約一兩分鐘後線上版就會更新。

## 存檔與雲端同步

進度預設存在瀏覽器的 localStorage（鍵名 `trilingo.save.v1`），沒有後端。

**雲端同步**：到「設定 → 雲端同步」貼上一個只有 `gist` 權限的 GitHub 權杖，進度就會存到你 GitHub 帳號裡的一個私人 Gist（檔名 `trilingo-save.json`）。筆電、手機各連結一次之後，開啟 App、切回分頁、學習告一段落時都會自動同步。

- 合併規則是「進度只增不減」：段位 XP、星等、成就取較大值；單字熟練度取最後作答的那一份；設定與金幣取最後修改的那一份（`src/core/merge.ts`）。
- 限制：兩台裝置都在離線狀態下各自學習時，XP 取較大值而不是相加，其中一台離線期間多拿的 XP 會少算。
- 權杖只存在該裝置的瀏覽器（鍵名 `trilingo.cloud.v1`），不會包含在匯出的存檔裡。不用了可以到 GitHub 的 Settings → Developer settings → Personal access tokens 撤銷。

也可以到「設定 → 存檔」手動匯出／匯入 JSON。

## 語音

朗讀使用瀏覽器內建的 Web Speech API，有哪些語言的語音取決於瀏覽器與作業系統。Chrome 與 Edge 內建線上的英、日、韓語音；其他環境若缺少某個語言的語音，該語言的聽力題會自動改成其他題型，並在設定頁提示。
